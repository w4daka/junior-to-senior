Build and verify your todo

Turn your spec into running code, then prove it. 20 min. Think-first: you draft, agent grills.

Knowledge (3 min)

Your spec.txt says: track 3 todos in memory, add <text> or list, print 1. <text>, max 3 + ignore empty, no file/done/UI.

Strategic loop: build → run → verify. Tactics writes code. Strategy proves rule + boundary hold. Same loop as Beck red-green-refactor, shrunk: run two commands, check three boxes.

Retrieval check (2 min)

Q1. Which check proves your Rule holds?

Skill task (12 min, think-first)

  1. Draft todo.js yourself first — 10 lines max. Hint only: read process.argv, keep let todos = []. No copy-paste yet.
  2. Paste draft here. Agent grills, never solves outright (your rule).
  3. After 2nd try you may ask "show me". Then run:
    node todo.js add "buy milk"
    node todo.js list
  4. Verify with 3-box checklist: add+list, 4th ignored, no file.
Win: todo.js prints 1. buy milk and passes all 3 boxes.
