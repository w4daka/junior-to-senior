QA checklist for AI diffs

Run on every AI diff before merge. Stop at first fail.

L — Logic: does happy path print spec output?
    try: add milk → 1. milk
E — Edge: empty? 4th? unknown cmd? missing file?
    try: add "" → error, 4th add → error, foo → error
D — Design: one place for rule? no copy-paste?
    ask: max-3 in one if? print in one format?
N — Not-doing: no extra file/UI/done?
    check: ls, no new deps

Loop from Beck: fail → pass → clean. Post real diffs to r/code_review for wisdom.
