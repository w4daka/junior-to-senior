# Mission: Strategic Programmer

## Why
AI now handles tactical coding. I want the strategic skills that turn junior output into senior outcomes: plan work AI can execute, design codebases AI can't tangle, verify what AI produces.

## Success looks like
- Write a 1-page spec an AI agent can implement without clarifying questions
- Review AI-generated JS/TS and catch logic, edge-case, and design flaws before merge
- Design a small deep module with a simple interface hiding real complexity
- Diagnose a failing AI-built feature with a tight reproduce → isolate → fix loop

## Constraints
- Junior dev, JS/TS stack
- 15-30 min per lesson, mix of interactive quizzes + real-world tasks
- Lessons live in `./lessons/` as self-contained HTML

## Out of scope
- Tactical syntax tutorials (AI already covers this)
- DevOps / infra provisioning
- Management / career-ladder politics
